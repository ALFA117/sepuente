// El problema

Rampas SPEI sin
estándar común

Cada rampa MXN tiene su propia API.
Cada wallet tiene que integrarlas una por una.
✕
Sin estándar — Etherfuse, Bitso, Kushki exponen APIs propietarias incompatibles
✕
Descubrimiento manual — las wallets Stellar no pueden encontrar rampas MXN automáticamente
✕
Vendor lock-in — una sola rampa ata al usuario a un único proveedor regulado
✓
SEPuente — una integración para cualquier proveedor SPEI
// La solución

Una capa de protocolo,
no una rampa nueva

SEPuente traduce el protocolo. El KYC y el dinero se quedan en el proveedor regulado.
SEPuente solo convierte la interfaz.

🔓
No custodial
Nunca toca fondos ni llaves de usuarios

Open source
MIT · forkeable · auditable
☁️
Serverless
Sin background jobs · todo pull-on-read
🔌
Plug & play
Interfaz RampDriver · cualquier proveedor
