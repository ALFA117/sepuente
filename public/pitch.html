Cada rampa SPEI tiene
su propia API.
Cada wallet tiene que
integrarlas una por una.
  • ✕ Sin estándar común — Etherfuse, Bitso, Kushki exponen APIs propietarias incompatibles entre sí
  • ✕ Descubrimiento manual — las wallets Stellar no tienen mecanismo para encontrar rampas MXN automáticamente
  • ✕ Vendor lock-in — anclar a una sola rampa ata al usuario a un único proveedor regulado
  • ✓ SEPuente — expone cualquier rampa como anchor SEP-24 estándar. Una integración, cualquier proveedor.
// 01 — PROTOCOLO

Cómo funciona

SEPuente traduce el protocolo — el dinero y el KYC se quedan en el proveedor regulado.

🔍
Descubrimiento

La wallet lee stellar.toml y encuentra los endpoints automáticamente

🔑
Auth SEP-10

Challenge tx firmada en la wallet. JWT propio HS256, 24 h, sin estado en servidor

💱
Quote SEP-38

Precio y comisión en tiempo real desde el driver activo. Quote firmado con TTL

🏦
Instrucciones

CLABE + referencia SPEI para depósito. Dirección Stellar + memo para retiro

⚡
Liquidación

Pull-on-read actualiza el estado. TMXN acreditan en la wallet del usuario
