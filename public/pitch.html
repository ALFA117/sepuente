El puente entre
SPEI y Stellar

SEPuente convierte cualquier rampa de pesos mexicanos en un anchor estándar SEP-24, para que cada wallet compatible pueda ofrecer depósito y retiro SPEI sin integrar una sola API propietaria.

"Cada rampa MXN tiene su propia API. Cada wallet tiene que integrarlas una por una."
  • ✕Etherfuse, Bitso, Kushki — APIs completamente distintas, sin estándar común
  • ✕Las wallets Stellar no tienen forma de descubrir rampas fiat automáticamente
  • ✕Anclar a una sola rampa ata a los usuarios a un solo proveedor regulado
  • ✓SEPuente expone cualquier rampa como anchor SEP-24 estándar — una vez

Estándares Stellar

Cuatro SEPs,
una URL

Apunta cualquier wallet al dominio de SEPuente y obtiene el stack completo de estándares anchor.

SEP-1
Stellar Info
stellar.toml generado dinámicamente con todos los endpoints, activos y documentación del anchor.
SEP-10
Stellar Auth
Challenge transaction firmada con la cuenta del usuario. JWT propio firmado con HS256.
SEP-24
Hosted Deposit & Withdrawal
UI interactiva en popup o iframe. Depósito SPEI→TMXN y retiro TMXN→SPEI con historial.
SEP-38
Anchor RFQ
Cotizaciones en tiempo real. Precios, quotes firmados con TTL, contexto sep24 integrado.
